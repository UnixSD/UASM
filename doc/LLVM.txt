LLVM(Low-Level Virtual Machine, на данный момент официально не имеет расшифровки) - это фреймворк для создание компеляторов. На данный момент он разроботивается и поддержуется:

+-----------+--------------------+-----------------------+
+ Компания  + Компелятор на LLVM +          ОС           +
+-----------+--------------------+-----------------------+
+ Intel     +         ICC        +   Windows/Linux       +   
+-----------+--------------------+-----------------------+
+ Apple     +      Apple Clang   +       macOS           +
+-----------+--------------------+-----------------------+
+ Microsoft +         MSVC       +      Windows          +
+-----------+--------------------+-----------------------+
+   ROOT    +      Cling/Cint    + Кроссплатформ.(Cling) + <-- ROOT является группой по разроботке
+           +                    + Windows(Cint)         +
+-----------+--------------------+-----------------------+
+   LLVM    +        Clang       +   Кроссплатформеный   +  <-- LLVM Dev Team является группой по
+ Dev Team  +                    +                       +      разроботке и создателем LLVM
+-----------+--------------------+-----------------------+

----------------------------------Поддержуемие архитектуры------------------------------------------------
ARM, x86, PowerPC, RISC-V
Поддерожка RISC-V позволяет создавать програми с 128-битной розрядностью
----------------------------------------------------------------------------------------------------------

---------------------------------Поддержуемые языки програмирувания---------------------------------------
ActionScript, Ada, C#, Common Lisp, Crystal, CUDA, D, Delphi, Dylan, Fortran, Graphical G Programming Language, Halide, Haskell, Java (байткод), JavaScript, Julia, Kotlin, Lua, Objective-C, OpenGL Shading Language, Ruby, Rust, Scala, Swift, Xojo, Zig.
----------------------------------------------------------------------------------------------------------
(LLVM НЕ поддержует Python не смотря на то что на нем можно создать интерпритатор)
(LLVM НЕ поддержует Assembly только inline asm[2] в языках С и С++, тоисть в код на C/C++ добавляются asm вставки(с синтаксисом от AT&T, не от Intel[1]))

----------------------------------различные версии этого фреймворка---------------------------------------
LLVM IR - для анализа кода
LLVM JIT - для JIT[3] компеляции
LLVM Modules - для модулей 
LLVM Bitcode - для создания байткода(переводи код в 16 ричный двоичный код)
LLVM AOT - для AOT[3] компеляции
LLVM CodeGen - для генерации машиного кода
LLVM Assembly - для генерации ассемблерного кода
LLVM Machine Code - для создание готового машиного кода который можно запустить
----------------------------------------------------------------------------------------------------------

--------------------------------------Где используется----------------------------------------------------
1. для создания эмуляторов архитектур
2. для создания компеляторов и интерпритаторов
3. для мобильных и встроенных систем
4. для реализации новых языков программирования
5. для графики и видеоигр(для оброботки графики в игравих движках)
6. для безопасности и анализа уязвимостей
7. для научных вычеслений(поддержует лучшую оптимизацию для тяжолых вычеслений)
----------------------------------------------------------------------------------------------------------

-------------------------------------Дополнительно--------------------------------------------------------
[1] - синтаксис от AT&T отличается тем что добавляются дополнительные символы например:

+----------------------+-------------------+
+      от AT&T         +      от Intel     +
+----------------------+-------------------+
+  mov %%ebx, %%eax    +    mov ebx, eax   +
+----------------------+-------------------+

[2] - ассеблерные вставки в С/С++ можно добавить припомощу __asm__, например:
volotile __asm__ (
    "mov %%ebx, %%eax"
    "add %%eax, 1" 
);

[3] - JIT отличается от AOT, тем что:
AOT - компелирует программу перед запуском, тоисть в исполняемом файле есть компелятор или исходный код программы и перед запуском система или встроеный комппелятор, по такому принципу работает запуск программ в Android
JIT - компелирует программу во время выполнения, это полезно для тестирувания, и такой способ поддержует Live Coding[4], по такому принципу работает интерпритатор QML в Qt

[4] - Live Coding это функция JIT-интерпритатора которая позволяет во время исполнения кода видеть свои измения, например во время выполнения добавить какую-то функцию и изменения сразу отоброзятся с программе и не прийдется перезапускать интепритатор, но минус в том что если проект тяжолый то замена какой-то функции во время работы программы может вызвать высокую нагрузку на ЦП, и производительность падает. По такому принцепу работает движок V8 в браузерах на базе Chromium
